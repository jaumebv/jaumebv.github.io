Overview

Built at Coventry University, this project decouples multiplayer simulation from any single engine’s built-in replication layer. An authoritative C# server using ENet/UDP acts as the single source of truth for connections, teams, flag states, pickups and scoring.

Two independent clients—one in Unity (C#) and one in Unreal Engine (C++)—implement the exact same lightweight packet protocol so players on different engines share the same arena seamlessly.

Server, protocol & gameplay sync.

AUTHORITATIVE SERVER

Connections, UIDs & Broadcast Tick

On join, the C# server assigns a unique UID, balances teams and streams the current scoreboard and match state. Disconnections tear down player transforms cleanly across all peers.

  • Team & UID registries: Fast O(1) lookups for entity routing and clean disconnect teardown.
  • Dedicated packet router: Separate handlers for movement transforms, shots, flag transitions and pickup timers.

SHARED CLIENT ARCHITECTURE

Mirrored Unity & Unreal Clients

Both clients implement the exact same architectural boundary—NetworkManager and GameManager—over an engine-agnostic packet contract.

  • Deterministic packet contract: Identical message framing and coordinate mapping between Unity C# and Unreal C++.
  • Mirrored lifecycle: Spawning, interpolation and periodic sync driven by engine-native coroutines and timers.

COMBAT & CAPTURE THE FLAG

Shooting, Damage & Flag State Machine

Raycast aim spawns physical projectiles with lifetime tracking while two team flags transition strictly across Picked, Lost, Returned and Captured states.

  • Damage & flag drops: Friendly fire is blocked; reaching 0 HP automatically drops any carried flag and triggers respawn.
  • Capture rules: Capturing requires the home flag to be safely docked on base.
CTF State MachineHit relay
MATCH EVENTS & PICKUPS

Flag Captures & Synchronised Pickups

Health and Speed pickups share a unified base class; only the local client owner triggers a pickup request so the server broadcasts hiding and respawn timers to everyone.

  • Single-owner authority: Prevents duplicate pickup triggers from remote proxy avatars.
  • Server-timed respawns: Match scoreboard and pickup cooldowns stay synchronised across both engines.
