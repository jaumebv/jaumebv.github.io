Dipole Particle Simulation

GPU System · CUDA & OpenCL · Raylib · 2023/24

Overview

Dipole Particle Simulation is a GPU-accelerated 3D particle system written in C++, implementing two different multi-core APIs: CUDA and OpenCL. It simulates charged particles interacting within an electric field, optimising performance through parallel computation while comparing both APIs in terms of efficiency and scalability.

The project uses Raylib for window and camera management and OpenGL for rendering the 3D environment, leveraging CUDA–OpenGL interoperability for direct GPU-side rendering. Each implementation computes electric field forces and particle motion entirely on the GPU, achieving real-time framerates even with thousands of active particles.

  • Language: C++
  • APIs: CUDA & OpenCL
  • Renderer: Raylib + OpenGL
  • Performance: 1M particles and 5K particles configurations tested on high-end PCs

Implementation

CUDA Implementation

The CUDA version uses Raylib for windowing and camera control, OpenGL for particle rendering, and CUDA–OpenGL interoperability for direct GPU data sharing. Each particle is processed on the GPU through a kernel that computes electric field forces and updates positions efficiently across thousands of threads.

Custom pseudo-random generation based on thread indices replaces CURAND, resulting in a substantial improvement in performance and frame stability. The simulation runs smoothly with up to one million particles, maintaining excellent responsiveness even with lighter 5,000-particle configurations.

OpenCL Implementation

The OpenCL implementation closely follows the CUDA design, adapting syntax and resource handling for the OpenCL runtime. It establishes OpenGL–OpenCL interoperability via shared buffer objects, allowing the GPU to render directly without CPU memory transfers.

Although setup and error handling in OpenCL are more complex, runtime performance remains close to CUDA, maintaining stable behaviour and efficient memory usage across both small (5,000) and large (1,000,000) particle simulations.

CUDA vs OpenCL Comparison

Both APIs achieved nearly identical results when scaled to one million particles, maintaining stable performance and memory usage. CUDA proved slightly faster and more efficient in resource utilisation, thanks to its optimised compiler and integrated developer tools.

OpenCL, however, offers the advantage of cross-platform support and compatibility with non-NVIDIA hardware, making it ideal for broader applications. Overall, CUDA provided higher performance-to-development efficiency, while OpenCL demonstrated greater flexibility.
