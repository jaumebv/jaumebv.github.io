Procedural Salamander AI

2D Simulation · Raylib (C++) · 2023/24

Overview

Procedural Salamander AI is a 2D simulation built in C++ using Raylib by a three-person team. Inspired by Rain World and similar titles, it explores how inverse kinematics, procedural animation, and AI-driven behaviours can generate lifelike, emergent movement without using traditional keyframed animation.

  • Engine: Raylib (C++)
  • Team: Juan Avilés, Jaime Garrido, and Jaume Berbel
  • Scope: AI · Animation
  • Year: 2023/24
  • Project type: Academic (AI module final project)

Key Features

Inverse Kinematics for Limbs

Custom 2D IK algorithms animate each leg dynamically without predefined keyframes. Limbs adjust to terrain and avoid intersections, producing grounded, natural poses.

Procedural Tail and Body Motion

A spring-mass physics system drives the salamander’s flexible tail and body, giving a snake-like, fluid behaviour that reacts naturally to forces and collisions.

Reactive Fly Behaviour

AI-driven flies wander randomly and flee when the salamander approaches, generating emergent predator-prey interactions that feel spontaneous and alive.
