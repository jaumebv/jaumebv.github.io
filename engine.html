MORDIBONX

Custom C++ Rendering Engine · OpenGL · 2023/24

Overview

MORDIBONX is a fully custom C++ rendering engine developed using OpenGL, built to implement modern real-time rendering techniques such as deferred rendering, post-processing effects, and a multi-threaded architecture with an in-house multithreaded job system. It was designed to serve as a learning platform for low-level engine design, combining rendering theory, ECS architecture, and real-time graphics programming.


  • Language: C++
  • Graphics API: OpenGL
  • Development time: 7+ months
  • Team: Jaume Berbel & Guillem Llorach
  • Year: 2023/24

Core Systems

Engine Architecture & ECS

The engine is structured around an Entity-Component-System (ECS) architecture, enabling efficient data management and modular entity behaviour. It includes a Resource Manager for dynamic model loading, a Job System for multi-threaded task execution, and a CameraPhoto utility that captures real-time scene snapshots asynchronously.

The Engine class orchestrates all core systems, coordinating rendering modes (forward and deferred), resource initialisation, and shader management. The Window system integrates ImGui for in-engine editing and live debugging.

Rendering Pipeline

MORDIBONX supports both forward and deferred rendering pipelines. The forward pass computes lighting directly per object, ideal for simple scenes, while the deferred approach separates geometry and lighting, efficiently handling multiple dynamic light sources.

The engine includes shadow mapping for directional, point, and spot lights using depth buffers and cubemap techniques. Each light contributes to a multi-pass lighting stage, accumulating the final image through additive blending.

Post-Processing & Photo Mode

Using framebuffer rendering, MORDIBONX applies multiple post-processing effects such as blur, pixelation, contrast adjustment, grayscale, negative, and cartoon shading. These are implemented via dedicated GLSL fragment shaders, applied over a full-screen quad.

Additionally, the Photo Mode integrates with the Job System, enabling real-time screenshot capture without interrupting the render loop — offloading image saving to background threads for optimal performance.

Challenges & Takeaways

Developing MORDIBONX was an exercise in both technical depth and problem-solving. Implementing ECS, multi-threading, and deferred rendering demanded solid understanding of modern C++ and graphics APIs. Shadows and GBuffer management proved particularly challenging but essential to the final result.

Through trial, debugging, and team collaboration, the engine evolved into a modular, extensible base for real-time rendering projects. This project deepened our understanding of how professional engines manage rendering pipelines, parallelism, and performance.
